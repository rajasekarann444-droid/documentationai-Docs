## Overview

The Frameworks module helps you view and track compliance frameworks configured in Stakflo.

## Frameworks Page

The page provides two tabs:

<Image src="https://blob-cdn.documentation.ai/org-eebb0ffa-5837-4323-ba46-75da413866bf/doc-cf03db34-2b0f-4475-8759-f7336cd28535/1792060724321-guj9e7a1r8l-pasted-image-1792060872721.png?fm=auto&auto=compress%2Cformat" width="394" height="263" alt="" style="width: 394px; height: auto; cursor: pointer;" />

- **Active Frameworks:** View frameworks currently active in your organization.
- **All Frameworks:** Explore the available frameworks.

Use the search field to find a framework by name. Use the category filter to narrow the list.

## Framework Details

Each framework card displays key information about the framework, including its name, progress, unified controls, clauses, and controls.

For example, the active ISO 27001:2022 framework displays:

- **Progress:** 4%
- **Unified Controls:** 166
- **Clauses:** 7
- **Controls:** 93

Select **View Details** on a framework card to explore its details.\\
