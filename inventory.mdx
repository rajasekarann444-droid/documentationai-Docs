## Overview

The Inventory page provides a centralized list of third-party vendors and their risk information.

## Search and Filters

- **Search:** Find vendors by organization name or email.
- **Filter:** Use the filter control to narrow the vendor list.
- **Add Third-Party Vendor:** Open the available action to begin adding a vendor.

## Inventory Table

The table includes the following columns:

| Column            | Description                               |
| ----------------- | ----------------------------------------- |
| Organization Name | Name of the vendor organization.          |
| Email             | Vendor contact email.                     |
| Website URL       | Vendor website address.                   |
| Category          | Vendor category.                          |
| Inherent Risk     | Risk level before controls or mitigation. |
| Residual Risk     | Risk level after controls or mitigation.  |
| Status            | Current vendor status.                    |
| Action            | Available actions for the vendor record.  |

Some columns support sorting, including organization name, email, category, inherent risk, and residual risk.

## Empty State

If no vendor records match the current view, the page displays **No data found**.
