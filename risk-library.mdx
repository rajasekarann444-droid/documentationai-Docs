## Overview

The Risk Library provides a collection of predefined risk scenarios that you can review and add to your Risk Register. Scenarios added from the library appear in your [Risk Register](/risk-register) for ongoing tracking and assessment.

See [Risk Management Overview](/risk-management-overview) for risk summary metrics and analysis panels.

## Search and Filters

- **Search by name:** Find risk scenarios by name.
- **Filter:** Narrow the displayed scenarios using the available filters.
- **Table View:** View risk scenarios in a tabular layout.
- **Grid View:** Switch to a grid layout.

## Risk Library Table

The table displays the following information:

| Column     | Description                                                                             |
| ---------- | --------------------------------------------------------------------------------------- |
| Name       | Name of the risk scenario.                                                              |
| Category   | Category associated with the scenario.                                                  |
| Controls   | Controls associated with the scenario. Additional controls may be indicated by a count. |
| Frameworks | Compliance frameworks mapped to the scenario.                                           |
| Frequency  | Frequency associated with the scenario.                                                 |
| Action     | Add the scenario to the Risk Register.                                                  |

## Add a Risk Scenario

1. Find the relevant scenario using search or filters.
2. Review its category, associated controls, framework mappings, and frequency.
3. Select **Add** in that scenario's row to add it to the Risk Register.

## Pagination

The page displays the number of records and provides pagination controls. You can change the number of rows displayed per page and navigate between result pages.
