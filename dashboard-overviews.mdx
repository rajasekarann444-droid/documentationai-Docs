The Stakflo dashboard provides a central view of your organization's compliance progress and highlights activities that may need attention.

<Callout kind="info" collapsed="false" color="#10b981">
  The dashboard reflects Stakflo's **Always Audit-Ready** and **Compliance Visibility** capabilities — always-on monitoring with real-time insight into control coverage, compliance posture, and audit readiness. See the full list of advertised capabilities on the [Introduction](/stackflo-introduction) page.
</Callout>

## Dashboard Layout

The dashboard includes the following sections:

- **Navigation Sidebar:** Access the available application modules.
- **Top Navigation Bar:** View the page title, organization logo, and notifications.
- **Compliance Journey:** Track progress through the compliance setup stages.
- **Framework Status:** Review framework progress and mapped controls.
- **Policy Status:** View policy counts by status.
- **Recent Tasks:** Review recent risk and audit tasks.

## Quick Actions

Quick Actions help you track key setup activities:

- **Update Organization Profile:** Add organizational details such as mission, vision, and operational boundaries.
- **Workforce (HRMS):** Connect your HRMS.
- **Roles & Responsibilities:** Assign compliance owners.

The dashboard displays the status of these activities so you can identify what remains to be completed.

## Framework Status

The Framework Status section summarizes framework progress. For example, the dashboard displays ISO 27001:2022 with its progress percentage and mapped control count.

## Policy Status

The Policy Status section summarizes policies by status, including Published, In Review, and Draft. Use **View details** to explore the policy information.

## Recent Tasks

The Recent Tasks section provides Risk and Audit tabs for reviewing relevant tasks. If no tasks are available, the dashboard displays an empty state.
