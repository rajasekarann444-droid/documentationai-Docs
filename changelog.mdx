## Product updates

See what's new in ComplyHub. This page covers the latest features, enhancements, and bug fixes across each release.

<Update label="January 2025" description="v4.2.0" tags={["release"]}>

### New

- **ISO 27701 framework support:** Extends privacy information management alongside existing ISO 27001 certifications
- **AI-powered policy mapping:** Automatically suggests control mappings when uploading custom policies
- **Trust Portal subscriptions:** Allows external stakeholders to subscribe to your trust portal for real-time compliance updates
- **Bulk evidence upload:** Automatically categorizes documents using document classification

### Improved

- Dashboard load times reduced by 40% with optimized evidence queries
- Policy editor now supports markdown tables and rich text formatting
- Integration health monitoring now proactively alerts 7 days before token expiration
- Task Center filters now persist across sessions

### Fixed

- Resolved an issue where SSO group mappings did not update when IdP group names changed
- Fixed evidence collection failure for AWS CloudTrail in multi-account setups
- Corrected readiness score calculation when controls are marked N/A

</Update>

<Update label="December 2024" description="v4.1.0" tags={["release"]}>

### New

- **NIST CSF 2.0 framework:** Added with 108 controls
- **Custom framework builder:** Create your own control set for non-standard compliance requirements
- **Vendor risk assessment templates:** Includes scoring automation

### Improved

- Audit center now supports parallel audit tracks for multiple frameworks
- Evidence auto-renewal now supports time-sensitive documents such as certificates and policies

### Fixed

- Fixed notification badge not clearing after reading all alerts
- Resolved CSV export formatting issues in evidence reports

</Update>

<Update label="November 2024" description="v4.0.0" tags={["release"]}>

### New

- **Unified Control Framework 2.0:** Map one control across 12+ frameworks simultaneously
- **Real-time compliance dashboard:** Includes trend analysis
- **Slack and Microsoft Teams integration:** Supports task notifications

### Improved

- Redesigned onboarding wizard with four-section guided setup
- Policy portal now supports multi-language publishing

### Fixed

- Various UI improvements and accessibility enhancements

</Update>
