## Overview

Unified Controls provides a central view of controls and their compliance status across mapped frameworks.

## Overview Tab

The Overview tab summarizes control status through these metrics:

- **Compliant:** Controls marked as compliant.
- **Non-compliant:** Controls that are not compliant.
- **Not applicable:** Controls marked as not applicable.
- **Assigned:** Controls assigned to users.

The page also includes a Control Completion by Framework chart to help you review control progress for each framework.

## All Controls

The All Controls tab displays the control list in a table.

The table includes:

- Control name or reference
- Assignee
- Control domain
- Mapped frameworks
- Status
- Action

Use the search field to find a control and the available filters to narrow the list. The table also supports assigning controls and navigating between pages.

## My Approvals

The My Approvals tab displays controls requiring approval review.

The table includes control, control domain, category, frequency, frameworks, status, and action information.

Use the search field and status filter to find relevant approval items. If no records are available, the page displays an empty state.
